# Restaurant-food-order-forecasting
"A Machine Learning model using Linear Regression to predict restaurant food orders based on historical data."
# 📈 Restaurant Food Order Forecasting
*Developed by:* Niranjan Kumar Sharma

## 📝 Project Overview
Ye ek Machine Learning project hai jo pichle sales data ko analyze karke aane wale din ke orders predict karta hai.

## 🛠️ Tech Stack
* *Language:* Python
* *ML Library:* Scikit-Learn (Linear Regression)
* *Data Handling:* Pandas
* *Visualization:* Matplotlib

## 🚀 How to Run
1. Python install karein.
2. Libraries install karein: pip install pandas scikit-learn matplotlib
3. Code run karein: python main.py

Model Day 6 ke liye orders predict karta hai aur ek trend graph generate karta hai jo repository mein my_prediction_graph.png ke naam se save hai
